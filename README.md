# connectrip-ios

커넥트립(ConnectTrip) iOS 앱을 빌드하는 데만 쓰는 저장소입니다.

- 앱의 원본 코드는 비공개 저장소에 있습니다. 여기에는 이미 빌드된 웹 번들(`dist/`), iOS 프로젝트(`ios/`), 의존성 목록만 있습니다.
- 내용은 비공개 저장소의 동기화 스크립트가 통째로 바꿔 올립니다. 이 저장소에 직접 커밋하거나 PR을 보내도 반영되지 않습니다.
- 라이선스가 없습니다. 이 파일들을 다른 곳에 쓰지 마세요.

This repository only builds the ConnectTrip iOS app. The source code is private. No license is granted.
